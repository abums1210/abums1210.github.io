An isolated and enhanced version of the GTA IV styled scrolling radio HUD element for GTA III, GTA Vice City, and GTA San Andreas (made on @toufiq's request).

<!--more-->

### Features:
1. Can configure icon size and gap.
2. Can choose between colorful and grey icons in config (auto-generated after first run).
3. Can quick mute radio by pressing `X`.
4. Separate standalone plugin versions for GTA III, GTA Vice City, and GTA San Andreas.

### Changelog:

#### Version 1.8 (Final Update):
1. Config Toggle for bicycle radio icon display — disabled by default.
2. Colored off button icon.

#### Version 1.7:
1. Config Toggle to disable scrolling animation while entering vehicle.
2. Config Toggle to disable scrolling animation completely.
3. Toggle to show only the active radio station.
4. Disabled radio icon appearing while riding bicycles.
5. Fixed Track player icon showing while entering Ambulance/Police Vehicles/Fire trucks.
6. Added fade out animation.
