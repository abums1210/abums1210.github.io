### Requirements:
This HUD does not support widescreen resolutions. Thus you must install Widescreen fix, preferably the latest one as it scales it to IV radar dimensions:
- [GTA III Widescreen Fix](https://github.com/ThirteenAG/WidescreenFixesPack/releases/tag/gta3)
- [GTA VC Widescreen Fix](https://github.com/ThirteenAG/WidescreenFixesPack/releases/tag/gtavc)
- [GTA SA Widescreen Fix](https://github.com/ThirteenAG/WidescreenFixesPack/releases/tag/gtasa)

### How to install?
Just drop the plugins to your game directory.

### Features:
- Health/Armor/Breath (GTA SA) circular bars drawn by code.
- Animated stack for HUD elements. HUD will fade out after a while and priority stacking will occur on order of appearance.
- Scale and positional adjustments for HUD elements.
- Optional UITweaks plugin for message box, subtitle, zone, vehicle and mission text tweaks.
- No txd or image backend.
- Press "T" or pause and resume to show clock and other HUD elements at once.
- HUD colors will remain the same as native HUD. To modify them, use HUD color changing mods.
- This is supposed to be a barebones implementation of IV HUD with minimal features, aimed at compatibility with other mods.
- No features will be added and only bug reports will be fixed.

An ASI loader is required to run the mod:
- [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases)
